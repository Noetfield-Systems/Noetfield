An agent that mostly says no

Every morning at seven, a Noetfield agent screens a crypto watchlist, drafts a trade plan for anything that survives, and then checks its own plan with arithmetic. Almost every plan fails that check and is thrown away in public. That refusal is the product being demonstrated, not a malfunction.

A language model asked for a trade will produce one. It will produce one when the setup is good, and it will produce one when there is nothing there at all. The output looks identical in both cases: confident, fluent, specific. That is the failure mode behind most agent products, and it is not fixed by a better model or a stricter prompt.

It is fixed by refusing to let the model be the last word.

What it does

One run per day, at 07:00 Vancouver time. It pulls public market data for a watchlist, discards most candidates using plain arithmetic before any model is called, and asks a model to write a plan only for the few that survive.

Each plan is then put through a risk gate that does not ask the model anything. The gate checks that the entry, stop, and target are real finite numbers, that the reward justifies the risk, that the position size is valid. A plan that fails any check is rejected, and the specific reasons are published alongside it.

The result is a short daily brief listing what was screened, what was analyzed, what was rejected, and why.

What it does not do

It places no orders. It holds no positions and no money. It is not connected to an exchange, a broker, or any account, and there is no path in the code by which it could place a trade.

It is not investment advice and it is not a recommendation service. Nothing on this page or in the daily brief is tailored to any person's circumstances, and no one should treat a published brief as a reason to buy or sell anything.

No performance is claimed. There is no track record, no return figure, and no backtest presented as one. The agent has never taken a position, so it has never been right or wrong about one.

Why we run it

Noetfield sells deterministic controls around model output: structure that is checked rather than hoped for, with the failure caught before the answer leaves the system. That claim is easy to make and hard to show, because the interesting case is the one where the model is wrong and something stops it.

Markets supply that case every day, on material where a wrong answer is obviously expensive. So we pointed the same machinery at a domain that punishes false confidence, put it on a fixed schedule, and published the result whether or not it flatters us.

The record so far

As of 7 August 2026, across eight daily cycles: 96 symbols screened, seven plans drafted by the model, and none of the seven cleared the risk gate. Total model spend for all eight runs was about three cents.

A gate that has passed nothing yet is not proof that the gate is well calibrated. It is consistent with a correctly cautious system and also with one that is too strict to ever act, and eight cycles is not enough to tell those apart. The live brief is published so that this stays checkable rather than asserted.

Stated plainly

The daily brief is published free and can be read without an account. The live page also lists a paid delivery tier; it is not active, no payment is taken, and no subscription can be started today.

The market data comes from public sources and is not independently audited. The gate enforces the rules it was given; it does not know whether those rules are the right ones. A published rejection proves the gate ran and what it decided. It does not prove the decision was correct.
