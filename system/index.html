How the pieces fit

Five jobs. Propose the work, allow it, run it, judge it, and name the path. The thing that runs the work does not decide if the work is good.

Who does what

  • Propose. A model or helper can suggest the next step. It cannot run that step.
  • Allow. Identity, policy, and budget decide whether the step is permitted.
  • Run. Only the permitted step happens, and what happened is written down. How a run is allowed
  • Judge. A separate check looks at the record. It can accept, reject, repair, or stop. The runner does not mark its own homework.
  • Path. A named way of doing one kind of job, with a stop if it cannot finish honestly. Public paths
