## Product positioning

**Noetfield Systems Inc.** builds and operates governed AI execution/evidence infrastructure. **Noetfield App** is its intended universal AI software builder: real source creation, isolated code execution, tests, live previews, code editing, publishing, and optional autonomous Company OS for maintaining software and supporting genuine customer/growth operations.

The app is **not** a website-only builder, CRM platform, generic compliance dashboard or a product limited to lead-follow-up workflows. These may be supported optional use cases, without changing the universal software-creation mission.

**Noetfield Runtime** is the canonical public name of the technical engine. **Runway** remains the historical package/service identifier only until compatibility-preserving migration is verified.
