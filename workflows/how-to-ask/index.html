Workflows · How to ask

Asking for a workflow

Type it in plain language, name the apps, get a workflow.json you can import.

Start here

Begin your request with n8n workflow: — the colon selects the recipe. Then describe what should happen in plain language.

The shape that works

When [something happens in a named app], [do something] in [a named app].

Four requests in the shape that works:

  • n8n workflow: when a Calendly event is booked, add it to Google Calendar and send a confirmation email via Resend
  • n8n workflow: when a Typeform response arrives, create a contact in HubSpot and notify #sales in Slack
  • n8n workflow: when a Stripe payment fails, send an email via Resend and create a follow-up task
  • n8n workflow: when a Shopify order is created, add a row to Google Sheets

Three rules that decide whether it works

Name the apps. “When a form is submitted” does not say which form. “When a Typeform response arrives” does. Every app you name becomes a real node with a real type, so a vague app is a vague workflow.

One trigger, up to three actions. A workflow begins with a single event. If your sentence contains “and separately” or “and also, every morning”, that is a second workflow. Ask for it on its own line.

Include the destination detail. “Notify Slack” builds. “Notify #sales in Slack” builds better. Channel names, sheet names, list names, and field names all land in the output if you put them in the request.

What comes back

A workflow.json you can download and import straight into n8n. Credentials arrive as named placeholders — your keys are never written into a generated file. You connect your own accounts when you import.

What is checked before it reaches you

Every delivered build carries its check results on the card. Read them before you import. If a check did not pass, the card says so rather than rounding up.

When it will not work

Requests that describe an outcome rather than a sequence — “clean up my sales process”, “make onboarding better” — do not have a trigger, so there is nothing to build. Decide what event starts the work, then ask again.
